# Pack — idle RPG с активным таймингом (рабочее название)

Мобильный прототип (портрет, ~390×844). Вид от первого лица: героя не видно, передний моб крупно в центре, остальная стая уменьшенными копиями уходит цепочкой к левому верхнему углу. Бой идёт сам (авто-атака), игрок вмешивается таймингом двух кнопок.

Игра — `index.html` + `css/game.css` + скрипты в `js/` (canvas, без зависимостей и сборки). Открывается двойным кликом по `index.html`. Git-репозиторий в этой папке; исходный однофайловый вариант — тег `v0-single-file`.

## Файлы
Скрипты — обычные `<script src>` (не ES-модули, чтобы работало через file://), общая глобальная область, порядок подключения важен: каждый файл может на верхнем уровне использовать только то, что объявлено в файлах выше. Порядок: `core` (случайные числа, кривые, предметы, урон; без DOM) → `tune` (TUNE, константы, localStorage) → `state` (S) → `biome` (биомы) → `pack` (стая) → `tutorial` → `progress` (опыт, лут, побег) → `combo` (серия) → `combat` (бой, `step`) → `input` (кнопки) → `audio` → `render`, `render-mob`, `render-fx` (canvas) → `circle` (версия «кружок») → `hud` → `inventory` (рюкзак) → `settings` (вкладка «Настройка») → `save` (сохранение прогресса) → `auto` (авто-режим и оффлайн) → `controls` (обработчики) → `main` (цикл и запуск).

## Проверки (нужны Node и Playwright с Chromium)
- `node tests/smoke.mjs` — игра открывается через file://, бой идёт, рюкзак ставит паузу, ошибок в консоли нет.
- `node tests/equivalence.mjs` — 5 сценариев с фиксированным seed и виртуальными часами (бот, пассивная игра со смертями, обучение, рюкзак/вкладки/ползунки, скорость ×3) на эталоне из git и на текущих файлах; сравниваются состояние боя, текст интерфейса и картинка canvas кадр в кадр. Для рефакторинга без изменения поведения должно быть «совпали один в один». Эталон по умолчанию — `v0-single-file`, другой: `--ref <коммит>`. После намеренного изменения поведения сравнивать с коммитом до него уже бессмысленно — новый эталон = новый коммит. `--tune '{...}'` — добавить настройки во все сценарии (например, выключить новую механику), `--no-ui` — не сравнивать текст интерфейса (когда в «Настройке» появились новые пункты).
- `node tests/save.mjs` — сохранение: прогресс переживает перезагрузку и закрытие вкладки, посреди боя память откатывается к началу стаи, экспорт/импорт строкой, кривые и битые сохранения не роняют игру, «Начать заново» с подтверждением. Игру отдаёт локальный сервер (headless Chromium иногда теряет localStorage file:// при перезагрузке).
- `node tests/auto.mjs` — авто-режим (включается через 15 с без нажатий, сам блокирует, смерть не забирает рюкзак, кадр смерти и вопрос проходят сами, нажатие выключает) и оффлайн (экран «Пока вас не было», предел 8 ч, меньше 2 мин и время «из будущего» — без начисления).
- `node tests/combo.mjs` — серия: «идеально» при нажатии на щелчок, ступени до ×1.5 и бонус к опыту, сброс пропущенным ударом, в авто серии нет, тумблер выключает, рекорд в сохранении.
- `node tests/biome.mjs` — биомы и главари: смена по чекпоинту, надпись и запись в «Инфо», модификаторы, круг заново с +2 к уровню, отступление не уводит в прошлый биом, стая главаря, фазы и двойной удар, награда, тумблер выключает.
- `node tests/circle.mjs` — версия «кружок»: все мобы — кружок, он бегает по дугам у кнопок и перепрыгивает между ними, краснеет; касание по красному убивает моба, не успел — урон, тычок по зелёному — откат, удержание двигает область; бот проходит стаи.
- `node tests/bats.mjs` — налёт летучих мышей: прилёт, кнопка у мыши не работает, без урона, касание по красной убивает, бот проходит стаи, тумблер выключает.
- `node tests/sim.mjs` — симуляция баланса: прогоны активным, средним и пассивным ботом, вывод — уровень в час, стаи, смерти, отступления, доля сбежавших, доля блоков. Параметры: `--runs`, `--minutes`, `--profiles "имя:skill:jitter,..."` (jitter — разброс нажатия по окну, 0 — ровно на щелчок, 1 — где угодно в окне), `--tune '{...}'`, `--no-equip`.
- `node tools/build.mjs` — сборка в один файл `dist/pack.html` (для передачи одним файлом; проверка: `node tests/equivalence.mjs --target dist/pack.html`).

## Правила работы
- Язык интерфейса и общения — русский.
- Механики и цифры ниже — согласованы с автором. Не менять баланс и поведение без явной просьбы.
- При рефакторинге (разбиение на модули) поведение должно остаться один в один.
- После правки: открыть игру, убедиться, что нет ошибок в консоли и бой идёт (`node tests/smoke.mjs`); при рефакторинге — `node tests/equivalence.mjs`.
- Настройки игрока хранятся в localStorage `arena.tune.v2`, прогресс — в `arena.save` (см. «Сохранение»); умолчания — `TUNE_DEFAULTS` в коде (это настройки автора для теста).

## Экран
- Слева сверху: плашка «стая» — число = уровень мобов текущей стаи; фоном 3 кубика памяти (см. «Память»).
- Справа сверху: уровень героя.
- Снизу во всю ширину: полосы здоровья и опыта.
- Над ними: две кнопки-четверти круга по углам — «Защита» (щит, слева) и «Атака» (меч, справа). Между ними — бугорок рюкзака.
- Подсказки: кнопки подсвечиваются в момент, когда надо жать (щит — красным для блока, меч — золотым для удара); звуковой метроном (нарастание + щелчок в середине окна нажатия).
- Цифры урона: урон по мобам поднимается от кнопки атаки, урон по герою — к кнопке защиты, лечение героя «+N» — тоже к кнопке защиты (так задумано), при этом светится зелёным рюкзак.

## Основа боя
- **Авто-атака** героя по переднему мобу (база 900 мс, ускоряется статами).
- **«Атака»** сама урона не наносит. Работает только в окнах: контратака после блока, раскол щита в такт, прерывание каста хилера. Антидребезг 200 мс реального времени.
- **«Защита»** открывает окно блока (`guard` 150 мс + бонус), затем откат (`cool` 900 мс).
- **Усталость**: больше 3 нажатий защиты за `fatigueWindow` (900 мс) → откат ×2, при продолжении спама ×4. Нажатия во время отката тоже считаются. Проходит через 2,5 с.
- `speed` (0.5) — общий множитель времени: все длительности делятся на него.

## Ход ближнего моба (каждые `mobRate` ≈3600 мс ±15%)
- **Крит** (`critRate` 85%): меч поднимается, дрожит и раскаляется до красного, замирает наверху, бьёт вниз. Время замаха `lead` 500 мс. Урон ×2.5.
  - Блок в момент удара → урона нет, моб оглушён 1,2 с, окно **контратаки** 1,2 с (урон ×3; если добила — герой лечится на 15% макс. HP).
  - Оглушение закончилось, а моб жив (контру не нажали или она не добила) → моб **уязвим** (+25% получаемого урона за раз, максимум ×2).
  - Крит пропущен и у моба <28% HP → он **прячется** за следующего в очереди (не за хилера/дальника); защитник встаёт в блок. Не добил защитника за `retreatWindow` (8 с) → раненый **сбегает**.
- Иначе — обычный удар.

## Типы мобов
Шансы на спавне: хилер 20%, жёлтый 40%, дальник 32%, остальное — красный. Вожак всегда красный.

- **Красный (обычный)**. Только удар/крит. Сам в блок не встаёт — блок мечом (горизонтально, дрожит, «устаёт») только когда прикрывает раненого.
- **Жёлтый**. Круглый щит с самого спавна (3 положения: поднят / в руке / упал на ребро, серый). Щит раскалывается «Атакой» в такт пульсу (пульс 900 мс, окно `pulseWindow` 300 мс: 65% до, 35% после). После раскола сразу быстрый крит (`yellowCounter` 300 мс), его надо блокировать. Может снова поднять щит (`shieldRate` 55%). Промах по щиту → злость.
- **Дальник** (1 HP). Стреляет по своему таймеру (`rangedInterval` 2000 мс) из любого места стаи; перед выстрелом поднимает посох (700 мс), в синей сфере разгорается красное ядро. Шар летит к кнопке щита; удар засчитывается на краю кнопки. Блок отбивает шар в случайного моба стаи, это может быть и сам стрелявший (урон по прилёту). Слабее ближнего (×0.55).
  - Пропущенный обычный выстрел → **ярость**: глаза горят, следующий выстрел ×2.35, шар крупный с ореолом. Одна ступень, на один выстрел. Отбитый злой шар бьёт моба так же сильно.
- **Хилер** (1 HP, максимум 2 в стае). Посох с красной сферой. Каст начинается сразу, как только передний моб ранен (<92% HP); фиксирует цель на старте каста. Во время каста поднимает посох и дрожит; лечит цель: при 10% HP → +50%, при 70% → +10% (линейно). Интервал между кастами `healInterval` 5000 мс.
  - «Атака» в окне каста (где бы хилер ни стоял) → **прервано**, и это лечение достаётся герою по той же шкале. Если у переднего поднят щит, «Атака» сначала идёт в щит (раскол щита важнее, так задумано).
  - Нажал не вовремя → лечение срабатывает сразу.
  - Цель умерла во время каста → «каст сорван», хилер сразу кастует на нового переднего.

## Злость и вожак
- Промах по щиту → +1 злость мобу и вожаку (максимум 3). Каждый стак: +50% урона (`rageStep`) и корона над вожаком.
- Вожак с **3 коронами** (1 + 2 стака), если он не впереди, **сбегает**. В следующей стае он возвращается сразу злым (3 короны) и больше не сбегает.
- Пропущенный крит жёлтого после раскола щита тоже злит вожака.

## Память (адаптация стаи)
- Каждый побег (раненый или вожак) → память +1, максимум **3**.
- Каждая единица режет урон героя по стае на **15%** (×3 → −45%).
- Новая единица памяти начинает действовать со следующей стаи: кубик загорается сразу после побега, но урон в текущей стае не режется.
- Новый стак сбрасывает откат. Верхний стак держится **3 стаи**, потом снимается, и откат идёт для следующего.
- Индикация: кубики на плашке «стая». Количество = уровень памяти. Нижние всегда красные; верхний показывает откат цветом: красный (3 стаи) → жёлтый (2) → зелёный (последняя).

## Прогресс
- Опыт → уровень → статы (уровень лечит на прирост макс. HP).
- Уровень стаи = уровень героя + случайно −1/0/+1 + ⌊чекпоинт / 4⌋, от 1 до «уровень героя + 6».
- Чекпоинт (скрытый счётчик): +1 за зачищенную стаю. Если стая опустела из-за побега последнего моба, она не засчитывается.
- Стая: от `packMin` 3 до `packMax` 5 мобов; вожак при 3+.
- Смерть → кадр смерти: бой замирает целиком, карточка «Герой пал» (уровень стаи, сколько ненадетых вещей потеряно), дальше — по кнопке «Дальше» (в авто — сама через 3 с). В этом кадре больше ничего не засчитывается.
- 2 смерти подряд → вопрос (после «Дальше»): сменить снаряжение или **отступить** (чекпоинт −3, не ниже −4; память −2).

## Лут и рюкзак
- Дроп: вожак всегда, остальные 34%. Редкости common → legendary, случайные аффиксы.
- Надевается вручную в рюкзаке. Сверху закреплена карточка сравнения выбранной вещи с надетой.
- Рюкзак открывается на весь экран. Сверху только заголовок, всё управление (вкладки и «Закрыть») — внизу, под большой палец. Касание, открывшее рюкзак, во вкладки не проваливается — срабатывает только следующее нажатие.
- Ползунки в «Настройке»: сначала тап по строке выбирает ползунок, потом его можно двигать; невыбранные палец не сдвигает, прокрутка снимает выбор.
- Рюкзак мигает, пока в нём есть непросмотренные вещи; после открытия вещи считаются просмотренными.
- Открытый рюкзак ставит бой на паузу (все таймеры сдвигаются).
- Смерть → теряется всё, что не надето (в авто-режиме — нет, см. «Авто-режим и оффлайн»).
- Рюкзак — только вещи, до 36 ненадетых. Полон → выбрасывается самая слабая (по подсказке `item.score`), это может быть и новая. «Уровень N», побеги, отступления, потери и «рюкзак полон» — во вкладке «Инфо» (последние 60).

## Сохранение
- Ключ `arena.save` в localStorage, JSON с версией формата `v` (сейчас 1); старые версии переводятся цепочкой `MIGRATIONS` в `js/save.js`.
- Сохраняются: уровень, опыт, текущее HP, убийства, надетое, рюкзак (с отметкой «просмотрено»), «Инфо», чекпоинт, память и её откат, вернувшийся вожак, смерти подряд. Вкладка «Замеры» не сохраняется (замеры сессии).
- Пишется после событий (конец стаи, уровень, дроп, надеть/удалить, смерть, побег, отступление, открытие рюкзака) в конце кадра (главная точка — переход к следующей стае), а также при сворачивании и закрытии вкладки (`visibilitychange`, `pagehide`, `beforeunload`). Посреди стаи в хранилище лежит снимок с её начала: вышли из игры посреди боя — опыт, лут и убийства этой стаи пропадают (нельзя фармить одну стаю, например вожака, перезаходом); побег за этот бой всё же засчитывается. Смерть сохраняется сразу. Обучение — «стая 0»: в нём не сохраняется, первое сохранение — на переходе к стае 1; есть сохранение — обучение считается пройденным (`tutDone`).
- Текущая стая не сохраняется: после загрузки идёт новая с состоянием на её начало (HP тоже). Закрыли на вопросе после 2-й смерти — вопрос задаётся снова.
- Кривые значения приводятся в допустимые границы, непонятные вещи отбрасываются. Непрочитанное сохранение откладывается в `arena.save.broken`, начинается новая игра, в «Инфо» — «Сохранение повреждено».
- Рюкзак → Настройка: «Скопировать сохранение» (строка `PACK1:` + base64 JSON), «Вставить сохранение» (проверка и подтверждение, затем перезагрузка), «Начать заново» (подтверждение; настройки и флаг обучения не трогает).

## Авто-режим и оффлайн
- **Авто** включается сам, если `autoAfter` (15 с, реальное время) не нажимали «Защиту»/«Атаку» и не открывали рюкзак; выключается первым нажатием. Под уровнем героя — надпись «авто». В обучении авто нет. Ползунки в Настройке: «Авто-режим через» (0 — выключен) и «Авто-блок» (`autoBlock`).
- В авто герой с шансом `autoBlock` (35%, бросок на каждую угрозу): блокирует крит (обычный блок: стан, окно контры открывается, но жать её некому → моб уязвим), гасит выстрел дальника (без отбивания в моба), раскалывает щит в такт (дальше — обычный быстрый крит жёлтого). Не прерывает хилеров, не жмёт контру, не промахивается по щиту.
- Смерть в авто не забирает рюкзак; кадр смерти закрывается сам через 3 с (обратный отсчёт на «Дальше»); после 2 смертей подряд — сам отступает к чекпоинту (как кнопка, в «Инфо» — «Авто: отступили»).
- **Оффлайн**: при загрузке — время с последнего сохранения (`savedAt`), при возврате на свёрнутую вкладку — сколько она была свёрнута. Меньше 2 минут или отрицательное — ничего. Предел `OFFLINE_CAP_H` 8 ч. Убийств = `OFFLINE_KILLS_PER_HOUR` × часы × `OFFLINE_EFF` (0,5 — оффлайн вдвое медленнее полупассива); темп — пассивный из симуляции (`js/auto.js`, пересчитать после изменений баланса). Опыт и дроп считаются как в бою (стаи от `packMin` до `packMax`, вожак, 34%), в рюкзак кладутся 6 лучших вещей (по `item.score`), остальные «рассыпались». Чекпоинт, память, HP не меняются, смертей нет.
- Экран «Пока вас не было» ставит бой на паузу, «Забрать» — продолжить. В «Инфо» — запись «Пока вас не было», в «Замерах» — время в авто и сколько поймал сам.

## Биомы и главари
- Биом — по чекпоинту: `bossEvery` (10) стай подряд, потом следующий. Порядок (названия — от автора): Русло реки → Пещера → Пустынный город → Метеорит, затем круг заново с +2 к уровню стаи за каждый пройденный круг (внутри обычного предела «уровень героя + 6»).
- Модификаторы: Русло реки — нет; Пещера — замах крита короче на 10% (`lead` ×0.9); Пустынный город — шанс хилера +10%; Метеорит — вожак появляется с 1 стаком злости (одна злость до побега).
- Фоны биомов по умолчанию выключены (лагали на телефоне автора): тумблер «Фоны биомов» (`biomeBg`); выключены — тёмный фон как до биомов, механика биомов (модификаторы, главари, надпись, иконка) остаётся.
- Фон — коридор к дальней точке очереди стаи между двумя сплошными огромными стенами, мельчающими к дальней точке: Русло реки (день) — вода и стены тростника с метёлками до верха экрана; Пещера (ночь) — скальные стены с кристаллами и свод из арок со сталактитами; Пустынный город (день) — сплошной ряд глинобитных домов; Метеорит (ночь) — гигантские валы кратеров с раскалёнными трещинами, зарево метеорита в дальней точке. Декор без `rnd()`, бой не сбивает.
- **Главарь** — последняя стая каждого биома (`chief`): двое обычных мобов свиты и главарь (вожак ×1.4 размером, HP ×2.5 и урон ×1.1 от вожака, опыт ×5, багровый ромб над коронами, широкая полоса HP вверху с отметками фаз). Не сбегает и не прячется; злость и короны — как у вожака. Сбежавший вожак ждёт следующей обычной стаи.
  - Фазы по HP: 1 (100–66%) — замах крита ×0.85; 2 (66–33%) — щит в такт как у жёлтого, после раскола — двойной удар (быстрый замах, через 1200 мс второй; контра только после второго блока); 3 (<33%) — урон ×1.25, ходы ×0.8 чаще. Переход: 1 с паузы, вспышка, «ФАЗА N».
  - Награда: вещь «Редкий» или выше, в «Инфо» — «Главарь повержен». Смерть на главаре — обычная.
- Отступление не уводит ниже начала текущего биома (тумблер «Отступление не уводит в прошлый биом», `biomePin`). В первом биоме — как раньше, до −4.
- Биом вычисляется из чекпоинта, отдельных полей в сохранении нет. В обучении и без «Адаптивной сложности» — фон как до биомов, без модификаторов и главарей.
- Настройка: тумблер «Биомы» (`biomes`), ползунок «Длина биома, стай» (`bossEvery`). С выключенным тумблером бой совпадает с версией до биомов один в один (`--tune '{"biomes":false}' --no-ui`).
- Дальше: финт главаря в 3-й фазе и его приём биома, карточки обучения для главаря и мобов биомов.

## Налёт летучих мышей
- В основной игре во всех биомах посреди боя раз в `batEvery` (15 с игрового времени, ±30%) прилетает летучая мышь (одна за раз; в обучении нет). Это механика версии «кружок»: бегает по дугам у кнопок, перепрыгивает между ними, краснеет на `circleRed`.
- Пока мышь сидит в дуге у кнопки, эта кнопка не работает (серая, на нажатие — «МЫШЬ»), авто-блок и авто-раскол щита по ней тоже. В прыжке кнопки свободны. Урона мышь не наносит.
- Касание по красной мыши (раньше кнопки под ней) — мышь убита, серия +1 («идеально» +2); не успел — следующий круг; тычок по зелёной — откат `circleCool`. В авто ловится с шансом `autoBlock`. Смерть героя — мышь улетает. Опыта и лута за мышь нет.
- Настройка: тумблер «Налёт летучих мышей» (`bats`), ползунок «Мышь прилетает раз в». С выключенным тумблером бой совпадает с версией до налёта один в один (`--tune '{"bats":false}' --no-ui`). Тест — `node tests/bats.mjs`.
- Дальше: свои анимации и текстуры мыши в каждом биоме (автор).

## Версия «кружок» (прототип механики, обсуждается)
- Отдельная версия игры: `circle.html` (или `index.html?circle`; одним файлом — `dist/pack-circle.html` из `node tools/build.mjs`). Все мобы — «кружок»; свои настройки (`arena.circle.tune`) и сохранение (`arena.circle.save`), без обучения и биомов. Авто-атаки и ходов мобов нет: моб умирает только от касания.
- Кружок нарисован летучей мышью (зелёная / красная, в полёте часто машет крыльями, на остановке — медленно).
- Две области (рамок не видно, пунктир — только пока область двигают удержанием) — дуги вдоль скруглённого края кнопок «Защита» и «Атака», от края экрана до рюкзака (у края толще, к рюкзаку сужаются); кнопки в этой версии не нажимаются. Каждый новый кружок (новый моб или после пропущенного красного) — в случайной дуге. Зелёный кружок бегает перебежками вдоль дуги: скорость каждой — `circleSpeed` (440) ×0.5–1.8, остановки 100–1100 мс; с шансом 35% перебежка — прыжок через рюкзак в другую дугу. Через случайное время (от 40% до `circleGreen`, 3000 мс) он краснеет на `circleRed` (700 мс), продолжая бегать; вокруг — убывающая дуга времени.
- Касание по красному (радиус 40 px) — моб умирает (опыт, лут как обычно), серия +1 («идеально» +2 — в центральной доле `perfect` окна). Не успел — урон герою как от крита, серия сброшена.
- Тычок мимо или по зелёному — откат `circleCool` (900 мс): на кружке циферблат, касания не считаются.
- Удержание пальца на кружке дольше 450 мс — сдвигать ту дугу, где он сейчас; сдвиг запоминается (`arena.circle.arcs`).
- В авто кружок с шансом `autoBlock` бьётся сам.
- Область и кружок одинаковые для всех мобов; в биомах будут отличаться только графикой (автор придумывает).
- Ползунки «Кружок: …» в Настройке видны только в этой версии.

## Серия (комбо)
- Точные нажатия копят серию: блок крита, отбитый шар, раскол щита в такт, прерванный каст — +1, а «идеально» — +2; контратака — +1. **Идеально** — нажатие в центральной доле `perfect` (40%) окна, т.е. около щелчка метронома (у блока «ИДЕАЛЬНО» пишется вместо «БЛОК»/«ОТБИТО»).
- Ступени (`COMBO_TIERS`): с 5 — опыт за убийство ×1.1, с 15 — ×1.25, с 30 — ×1.5. Бонус только к опыту (выбор по умолчанию, урон и бой не меняются). Оффлайн бонуса нет.
- Сброс: пропущенный крит или выстрел, «МИМО» по щиту или не вовремя «Атака» при касте, нетронутый щит, каст хилера, который можно было прервать, усталость, смерть. Не сбрасывают удары, которые поймать было нельзя: щит в откате после нажатия, уже заблокировавшего другой удар (или сделанного до начала этого замаха), выстрел в момент, когда блок забрал крит в полёте, каст, пока у переднего щит (удар ушёл бы в щит). Обычные удары мобов и упущенное окно контры серию не трогают.
- В авто и в обучении серии нет; включился авто — серия молча обнуляется.
- Экран: счётчик под плашкой «стая» (ступень, счёт, полоска до следующей; цвет ступени зелёный → голубой → золотой), новая ступень — надпись «СЕРИЯ ×N» и аккорд, сброс — зачёркнутый счёт и глухой звук, при серии от 15 — «СЕРИЯ ПРЕРВАНА».
- «Замеры»: лучшая серия (сессия и за всё время, она в сохранении `combo.best`), % ручных блоков, % идеальных, доля времени боя с бонусом, итог прошлой стаи.
- Настройка: тумблер «Серия и бонус к опыту» (`combo`), ползунок «Зона „идеально“» (`perfect`). С выключенным тумблером бой совпадает с версией до серии один в один (`node tests/equivalence.mjs --ref <коммит до серии> --tune '{"combo":false}' --no-ui`).

## Обучение
- Включается само при первом запуске (флаг `arena.tutorial.done` в localStorage), заново — кнопкой «Пройти обучение» в Рюкзак → Настройка или `?tutorial` в адресе.
- Особая стая: обычный → жёлтый → обычный → вожак, за ними дальник и хилер. Уровень = уровню героя, память стаи не действует.
- Когда вид моба впервые выходит вперёд, бой встаёт на паузу и показывается карточка (5 шагов + «Обучение пройдено»). Дальник и хилер «спят», пока не выйдет вперёд второй обычный (будит дальника) и вожак (будит хилера); их карточка — при первом выстреле/касте.
- В обучении герой не умирает (остаётся 1 HP), вожак не сбегает. Есть кнопка «Пропустить обучение».

## Визуальные решения (согласованы)
- Ближний моб: шестигранник с рогами, пустые тёмные глаза. Дальник и хилер — узкий капюшон.
- Передний моб масштаб 2.5; очередь — геометрическая цепочка к левому верхнему углу, подтягивается после смерти переднего.
- Полоса HP моба — ровно по низу моба.
- Вспышки экрана: красная — урон, зелёная — лечение.
