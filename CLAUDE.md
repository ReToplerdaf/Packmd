# Pack — idle RPG с активным таймингом (рабочее название)

Мобильный прототип (портрет, ~390×844). Вид от первого лица: героя не видно, передний моб крупно в центре, остальная стая уменьшенными копиями уходит цепочкой к левому верхнему углу. Бой идёт сам (авто-атака), игрок вмешивается таймингом двух кнопок.

Игра — `index.html` + `css/game.css` + скрипты в `js/` (canvas, без зависимостей и сборки). Открывается двойным кликом по `index.html`. Git-репозиторий в этой папке; исходный однофайловый вариант — тег `v0-single-file`.

## Файлы
Скрипты — обычные `<script src>` (не ES-модули, чтобы работало через file://), общая глобальная область, порядок подключения важен: каждый файл может на верхнем уровне использовать только то, что объявлено в файлах выше. Порядок: `core` (случайные числа, кривые, предметы, урон; без DOM) → `tune` (TUNE, константы, localStorage) → `state` (S) → `pack` (стая) → `tutorial` → `progress` (опыт, лут, побег) → `combat` (бой, `step`) → `input` (кнопки) → `audio` → `render`, `render-mob`, `render-fx` (canvas) → `hud` → `inventory` (рюкзак) → `settings` (вкладка «Настройка») → `save` (сохранение прогресса) → `controls` (обработчики) → `main` (цикл и запуск).

## Проверки (нужны Node и Playwright с Chromium)
- `node tests/smoke.mjs` — игра открывается через file://, бой идёт, рюкзак ставит паузу, ошибок в консоли нет.
- `node tests/equivalence.mjs` — 5 сценариев с фиксированным seed и виртуальными часами (бот, пассивная игра со смертями, обучение, рюкзак/вкладки/ползунки, скорость ×3) на эталоне из git и на текущих файлах; сравниваются состояние боя, текст интерфейса и картинка canvas кадр в кадр. Для рефакторинга без изменения поведения должно быть «совпали один в один». Эталон по умолчанию — `v0-single-file`, другой: `--ref <коммит>`. После намеренного изменения поведения сравнивать с коммитом до него уже бессмысленно — новый эталон = новый коммит.
- `node tests/save.mjs` — сохранение: прогресс переживает перезагрузку и закрытие вкладки, посреди боя память откатывается к началу стаи, экспорт/импорт строкой, кривые и битые сохранения не роняют игру, «Начать заново» с подтверждением. Игру отдаёт локальный сервер (headless Chromium иногда теряет localStorage file:// при перезагрузке).
- `node tests/sim.mjs` — симуляция баланса: прогоны активным, средним и пассивным ботом, вывод — уровень в час, стаи, смерти, отступления, доля сбежавших, доля блоков. Параметры: `--runs`, `--minutes`, `--profiles "имя:skill,..."`, `--tune '{...}'`, `--no-equip`.
- `node tools/build.mjs` — сборка в один файл `dist/pack.html` (для передачи одним файлом; проверка: `node tests/equivalence.mjs --target dist/pack.html`).

## Правила работы
- Язык интерфейса и общения — русский.
- Механики и цифры ниже — согласованы с автором. Не менять баланс и поведение без явной просьбы.
- При рефакторинге (разбиение на модули) поведение должно остаться один в один.
- После правки: открыть игру, убедиться, что нет ошибок в консоли и бой идёт (`node tests/smoke.mjs`); при рефакторинге — `node tests/equivalence.mjs`.
- Настройки игрока хранятся в localStorage `arena.tune.v2`, прогресс — в `arena.save` (см. «Сохранение»); умолчания — `TUNE_DEFAULTS` в коде (это настройки автора для теста).

## Экран
- Слева сверху: плашка «стая» — число = уровень мобов текущей стаи; фоном 3 кубика памяти (см. «Память»).
- Справа сверху: уровень героя.
- Снизу во всю ширину: полосы здоровья и опыта.
- Над ними: две кнопки-четверти круга по углам — «Защита» (щит, слева) и «Атака» (меч, справа). Между ними — бугорок рюкзака.
- Подсказки: кнопки подсвечиваются в момент, когда надо жать (щит — красным для блока, меч — золотым для удара); звуковой метроном (нарастание + щелчок в середине окна нажатия).
- Цифры урона: урон по мобам поднимается от кнопки атаки, урон по герою — к кнопке защиты, лечение героя «+N» — тоже к кнопке защиты (так задумано), при этом светится зелёным рюкзак.

## Основа боя
- **Авто-атака** героя по переднему мобу (база 900 мс, ускоряется статами).
- **«Атака»** сама урона не наносит. Работает только в окнах: контратака после блока, раскол щита в такт, прерывание каста хилера. Антидребезг 200 мс реального времени.
- **«Защита»** открывает окно блока (`guard` 150 мс + бонус), затем откат (`cool` 900 мс).
- **Усталость**: больше 3 нажатий защиты за `fatigueWindow` (900 мс) → откат ×2, при продолжении спама ×4. Нажатия во время отката тоже считаются. Проходит через 2,5 с.
- `speed` (0.5) — общий множитель времени: все длительности делятся на него.

## Ход ближнего моба (каждые `mobRate` ≈3600 мс ±15%)
- **Крит** (`critRate` 85%): меч поднимается, дрожит и раскаляется до красного, замирает наверху, бьёт вниз. Время замаха `lead` 500 мс. Урон ×2.5.
  - Блок в момент удара → урона нет, моб оглушён 1,2 с, окно **контратаки** 1,2 с (урон ×3; если добила — герой лечится на 15% макс. HP).
  - Оглушение закончилось, а моб жив (контру не нажали или она не добила) → моб **уязвим** (+25% получаемого урона за раз, максимум ×2).
  - Крит пропущен и у моба <28% HP → он **прячется** за следующего в очереди (не за хилера/дальника); защитник встаёт в блок. Не добил защитника за `retreatWindow` (8 с) → раненый **сбегает**.
- Иначе — обычный удар.

## Типы мобов
Шансы на спавне: хилер 20%, жёлтый 40%, дальник 32%, остальное — красный. Вожак всегда красный.

- **Красный (обычный)**. Только удар/крит. Сам в блок не встаёт — блок мечом (горизонтально, дрожит, «устаёт») только когда прикрывает раненого.
- **Жёлтый**. Круглый щит с самого спавна (3 положения: поднят / в руке / упал на ребро, серый). Щит раскалывается «Атакой» в такт пульсу (пульс 900 мс, окно `pulseWindow` 300 мс: 65% до, 35% после). После раскола сразу быстрый крит (`yellowCounter` 300 мс), его надо блокировать. Может снова поднять щит (`shieldRate` 55%). Промах по щиту → злость.
- **Дальник** (1 HP). Стреляет по своему таймеру (`rangedInterval` 2000 мс) из любого места стаи; перед выстрелом поднимает посох (700 мс), в синей сфере разгорается красное ядро. Шар летит к кнопке щита; удар засчитывается на краю кнопки. Блок отбивает шар в случайного моба стаи, это может быть и сам стрелявший (урон по прилёту). Слабее ближнего (×0.55).
  - Пропущенный обычный выстрел → **ярость**: глаза горят, следующий выстрел ×2.35, шар крупный с ореолом. Одна ступень, на один выстрел. Отбитый злой шар бьёт моба так же сильно.
- **Хилер** (1 HP, максимум 2 в стае). Посох с красной сферой. Каст начинается сразу, как только передний моб ранен (<92% HP); фиксирует цель на старте каста. Во время каста поднимает посох и дрожит; лечит цель: при 10% HP → +50%, при 70% → +10% (линейно). Интервал между кастами `healInterval` 5000 мс.
  - «Атака» в окне каста (где бы хилер ни стоял) → **прервано**, и это лечение достаётся герою по той же шкале. Если у переднего поднят щит, «Атака» сначала идёт в щит (раскол щита важнее, так задумано).
  - Нажал не вовремя → лечение срабатывает сразу.
  - Цель умерла во время каста → «каст сорван», хилер сразу кастует на нового переднего.

## Злость и вожак
- Промах по щиту → +1 злость мобу и вожаку (максимум 3). Каждый стак: +50% урона (`rageStep`) и корона над вожаком.
- Вожак с **3 коронами** (1 + 2 стака), если он не впереди, **сбегает**. В следующей стае он возвращается сразу злым (3 короны) и больше не сбегает.
- Пропущенный крит жёлтого после раскола щита тоже злит вожака.

## Память (адаптация стаи)
- Каждый побег (раненый или вожак) → память +1, максимум **3**.
- Каждая единица режет урон героя по стае на **15%** (×3 → −45%).
- Новая единица памяти начинает действовать со следующей стаи: кубик загорается сразу после побега, но урон в текущей стае не режется.
- Новый стак сбрасывает откат. Верхний стак держится **3 стаи**, потом снимается, и откат идёт для следующего.
- Индикация: кубики на плашке «стая». Количество = уровень памяти. Нижние всегда красные; верхний показывает откат цветом: красный (3 стаи) → жёлтый (2) → зелёный (последняя).

## Прогресс
- Опыт → уровень → статы (уровень лечит на прирост макс. HP).
- Уровень стаи = уровень героя + случайно −1/0/+1 + ⌊чекпоинт / 4⌋, от 1 до «уровень героя + 6».
- Чекпоинт (скрытый счётчик): +1 за зачищенную стаю. Если стая опустела из-за побега последнего моба, она не засчитывается.
- Стая: от `packMin` 3 до `packMax` 5 мобов; вожак при 3+.
- Смерть → кадр смерти: бой замирает целиком, карточка «Герой пал» (уровень стаи, сколько ненадетых вещей потеряно), дальше — по кнопке «Дальше». В этом кадре больше ничего не засчитывается.
- 2 смерти подряд → вопрос (после «Дальше»): сменить снаряжение или **отступить** (чекпоинт −3, не ниже −4; память −2).

## Лут и рюкзак
- Дроп: вожак всегда, остальные 34%. Редкости common → legendary, случайные аффиксы.
- Надевается вручную в рюкзаке. Сверху закреплена карточка сравнения выбранной вещи с надетой.
- Рюкзак мигает, пока в нём есть непросмотренные вещи; после открытия вещи считаются просмотренными.
- Открытый рюкзак ставит бой на паузу (все таймеры сдвигаются).
- Смерть → теряется всё, что не надето.
- Рюкзак — только вещи, до 36 ненадетых. Полон → выбрасывается самая слабая (по подсказке `item.score`), это может быть и новая. «Уровень N», побеги, отступления, потери и «рюкзак полон» — во вкладке «Инфо» (последние 60).

## Сохранение
- Ключ `arena.save` в localStorage, JSON с версией формата `v` (сейчас 1); старые версии переводятся цепочкой `MIGRATIONS` в `js/save.js`.
- Сохраняются: уровень, опыт, текущее HP, убийства, надетое, рюкзак (с отметкой «просмотрено»), «Инфо», чекпоинт, память и её откат, вернувшийся вожак, смерти подряд. Вкладка «Замеры» не сохраняется (замеры сессии).
- Пишется после событий (конец стаи, уровень, дроп, надеть/удалить, смерть, побег, отступление, открытие рюкзака) в конце кадра, а также при сворачивании и закрытии вкладки. В обучении не сохраняется; сразу после него — сохраняется.
- Текущая стая не сохраняется: после загрузки идёт новая. HP — как было (перезагрузка не лечит), наказания за выход посреди боя нет. Память и вожак-беглец — как перед начатой стаей, если за этот бой никто не сбежал. Закрыли на вопросе после 2-й смерти — вопрос задаётся снова.
- Кривые значения приводятся в допустимые границы, непонятные вещи отбрасываются. Непрочитанное сохранение откладывается в `arena.save.broken`, начинается новая игра, в «Инфо» — «Сохранение повреждено».
- Рюкзак → Настройка: «Скопировать сохранение» (строка `PACK1:` + base64 JSON), «Вставить сохранение» (проверка и подтверждение, затем перезагрузка), «Начать заново» (подтверждение; настройки и флаг обучения не трогает).

## Обучение
- Включается само при первом запуске (флаг `arena.tutorial.done` в localStorage), заново — кнопкой «Пройти обучение» в Рюкзак → Настройка или `?tutorial` в адресе.
- Особая стая: обычный → жёлтый → обычный → вожак, за ними дальник и хилер. Уровень = уровню героя, память стаи не действует.
- Когда вид моба впервые выходит вперёд, бой встаёт на паузу и показывается карточка (5 шагов + «Обучение пройдено»). Дальник и хилер «спят», пока не выйдет вперёд второй обычный (будит дальника) и вожак (будит хилера); их карточка — при первом выстреле/касте.
- В обучении герой не умирает (остаётся 1 HP), вожак не сбегает. Есть кнопка «Пропустить обучение».

## Визуальные решения (согласованы)
- Ближний моб: шестигранник с рогами, пустые тёмные глаза. Дальник и хилер — узкий капюшон.
- Передний моб масштаб 2.5; очередь — геометрическая цепочка к левому верхнему углу, подтягивается после смерти переднего.
- Полоса HP моба — ровно по низу моба.
- Вспышки экрана: красная — урон, зелёная — лечение.
